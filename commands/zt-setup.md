---
description: First-time setup, or revisit what was settled before
---

Run `intake.py known` first. Ask about nothing it already reports.

Then `intake.py questions` and work through what is left. Read
`setup-stage1.md` before asking: it says how to conduct this, and in
particular which obvious questions must not be asked.

Store with `intake.py write`. If it refuses, a required answer is missing.
Go back and ask that one question rather than filling the gap with something
plausible.
